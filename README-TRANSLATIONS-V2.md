# Traducciones V2 de IvanLlopis.net

El paquete incluye:

- `translations.py`
- `translations/es.json`
- `translations/ca.json`
- `translations/eu.json`
- `translations/en.json`
- `translations/fr.json`
- `translations/uk.json`
- `translations/it.json`
- `translations/tr.json`

Los archivos contienen textos para navegación, hero, secciones, asistente de IA y pie de página.

Para usar el módulo desde `main.py`, importa:

```python
from translations import SUPPORTED_LANGUAGES, language_options, load_translations
```
