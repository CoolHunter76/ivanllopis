# Sprint 9 Visual v2

Este paquete añade un personaje visual junto al chat en escritorio, lo oculta en pantallas menores de 900 px y añade una pequeña atribución enlazada: `Powered by Llama 3.2 by Meta`.

## Uso

1. Descomprime en la raíz del repositorio.
2. Ejecuta `python scripts/apply-chat-visual.py`.
3. Ejecuta Ruff, formato y pytest.

El recurso `ai-assistant-companion.webp` fue generado con Microsoft Copilot y optimizado para web.

## Marca

No se incluye el logotipo corporativo oficial de Meta. La documentación pública de marca de Meta indica que el uso del logotipo requiere aprobación. La insignia incluida es una marca tipográfica propia, acompañada de atribución textual y enlace a llama.com. Sustituye la marca propia únicamente si dispones de un activo oficial y autorización aplicable.
